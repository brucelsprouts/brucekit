# brucekit — logo & identity brief

## What the app is

brucekit is a hotkey-summoned launcher for tiny personal utility tools on
Windows (Tauri v2 + React + Rust). Press a global hotkey, a compact command
palette appears, and you fire precision tools: OCR-grab any text on screen,
eyedrop any pixel's color, with more modules dropping in over time. It behaves
like a piece of precision equipment: instant, silent, always one keystroke away.

## Visual theme

Monochrome black-and-white technical HUD minimalism (matches brucelsprouts.com):

- Near-black ground (`#0a0b0d`), off-white foreground (`#f4f6f8`)
- The accent is **white with a soft glow** — color is an event, not decoration
- Monospace / technical typography, uppercase micro-labels, wide letter-spacing
- Thin 1px hairline borders, corner tick brackets, sharp corners (2px radius)
- No gradients, no glassmorphism, no drop shadows other than the glow
- Machine-readout framing: `// MODULES`, `STATUS`, `[ESC]` — diegetic sci-fi UI
- Reference points: cyberpunk diegetic interfaces, Swiss typographic grid,
  developer-terminal aesthetic, Linear/Vercel dark minimalism

## Image-generation prompt (paste as-is)

> Minimal app icon for "brucekit", a developer utility launcher. Monochrome
> sci-fi HUD aesthetic: near-black background (#0a0b0d), a single off-white
> glyph with a soft white glow. The glyph is a lowercase "bk" monogram set in a
> geometric monospace style, framed by four thin corner tick brackets like a
> camera viewfinder. Hairline 1px strokes, sharp square corners, flat design,
> no gradients, no color, no 3D, no bevel. Generous negative space, precise
> Swiss-grid alignment, terminal / diegetic interface feel — like an instrument
> panel readout. Subtle scanline texture at 2% opacity maximum. Centered
> composition on a square canvas.

### Variations to try

- Swap the "bk" monogram for a **crosshair + text-cursor hybrid** glyph
  (capture + text tools in one mark).
- Ask for "app icon, 1024×1024, flat vector style" for store/tray sizing.
- For a wordmark version: "BRUCEKIT in spaced uppercase monospace capitals,
  small corner brackets, white on near-black, soft glow on the letterforms".
